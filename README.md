# La Isabela | Glamping Boutique

Sitio web institucional para promocionar y reservar experiencias de glamping en La Isabela, ubicado en el corazón del Quindío, Colombia.

## Descripción

Esta landing page está diseñada para presentar el resort de forma elegante y atractiva, destacando sus experiencias, galería visual, tarifas, ubicación y un formulario de reserva integrado con WhatsApp y Formspree.

## Características

- Diseño moderno y premium con enfoque visual en naturaleza y lujo.
- Sección de inicio con video de fondo y miniaturas interactivas.
- Galería de imágenes con lightbox para visualización ampliada.
- Sección de tarifas con botones directos para reservar por WhatsApp.
- Mapa de ubicación integrado.
- Modal de reserva con formulario funcional.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- Formspree para el envío del formulario

## Requisitos

No se requiere instalación de dependencias. Solo necesitas un navegador web moderno.

## Cómo ejecutar

1. Abre el archivo `index.html` en tu navegador.
2. O, si prefieres, sirve la carpeta con un servidor local simple como:

```bash
python -m http.server 8000
```

Luego entra a:

```text
http://localhost:8000
```
